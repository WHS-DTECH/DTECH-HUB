Add Templates As Needed

  1. Open slideshow-template-library.js.
  2. Add a new object to TEMPLATE_LIBRARY with title, criteria, imageUrl, and templateUrl.
  3. Set status: "live" when the template is ready, or status: "coming-soon" to show it as upcoming.
  4. Save and publish. The listing will appear automatically in this library page.
