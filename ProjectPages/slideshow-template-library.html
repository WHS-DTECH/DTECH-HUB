Digital Outcome Description

Slide 1 for title and short outcome statement. Slide 2 for audience, purpose, and required functionality.

  • Include what the outcome is and does.
  • Identify end user and context.
  • Add success criteria for evaluation.

Speaker Notes: Criteria Mapping

Use Speaker Notes to map each slide to the assessment criteria you are addressing.

  • Paste or paraphrase the relevant criterion.
  • State evidence shown on that slide.
  • Keep notes concise and teacher-readable.

Link This To A Task Topic

  1. Open your Digital Outcome task topic card and select Edit Details.
  2. Paste a preview image URL into Slideshow Template Preview Image URL.
  3. Paste your Google Slides file URL into Slideshow Template File URL.
  4. Save. The right-side hero panel will show the preview image and a direct Open Slideshow File button.
