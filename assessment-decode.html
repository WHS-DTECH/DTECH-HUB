DECODE – Read the Question

Learn how to break down exam questions by identifying the Action, Quantity, Context and Detail. Understand exactly what the question is asking so you can plan a complete, relevant answer without missing important requirements.

Four things to look for in every question

  1. 1Action

    What am I being asked to do?

  2. 2Quantity

    How many things are required?

  3. 3Context

    What must my answer refer to?

  4. 4Detail

    What specific information must I include?

DECODE – Worked Example and Practice

1DECODE the question

Break it down

1Action
Describe, Give, Describe.
2Quantity
ONE specific example.
3Context
Nielsen's Error prevention heuristic in a human-computer interface.
4Detail
Explain the principle, provide an example and describe how it reduces user mistakes.

2Check the answer against DECODE

  • Action

    Describes the principle and explains how it reduces errors.

  • Quantity

    Provides exactly ONE example.

  • Context

    Uses error prevention in an appointment booking interface.

  • Detail

    Explains what the principle means, how it is applied and why it helps users.

Model Answer – DECODE Breakdown

1ACTION – Describe, Give, Describe

The answer performs three actions: it describes the principle, gives an example and describes how the example reduces errors.

2QUANTITY – ONE example

“For example, an online appointment booking system could grey out dates that are unavailable...”

Only one interface example is provided, as requested.

3CONTEXT – Error prevention in an interface

“...grey out dates that are unavailable, preventing users from selecting them.”

The example demonstrates how Nielsen's heuristic is applied in a human-computer interface.

4DETAIL – Explain how errors are reduced

“This reduces user errors because people can only select available appointments, avoiding incorrect bookings and saving time correcting mistakes.”

The answer explains the effect of the feature rather than simply naming it.

Write the model answer

Nielsen's Error prevention heuristic means designing an interface to stop users from making mistakes before they happen.

For example, an online appointment booking system could grey out dates that are unavailable, preventing users from selecting them.

This reduces user errors because people can only select available appointments, avoiding incorrect bookings and saving time correcting mistakes.

Remember DECODE helps you work out what to include in your answer before you start writing.

DECODE is not a paragraph-writing formula. It helps you identify everything your answer needs to include. You can then use 5Ws & H to develop your ideas and SEED to organise longer written responses.
