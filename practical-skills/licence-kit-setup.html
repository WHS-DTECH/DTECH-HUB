Unity Setup

Unity licence and Editor settings

Unity Licence Loader - Activity 1

Paste school-authorised licence information intended for students. Save to update the existing View School Licence button in Activity 1. The value is not displayed in the collapsed student view.

Leave blank to show: "School licence information is not yet available. Please ask your teacher."

Unity Editor - Activity 2

Full identifiers are supported, including patch and release suffixes, for example 6000.5.0f1. This updates the prominent version shown in Step 2.

Saved Editor settings appear when students open or reload Activity 2. These are the same settings available in Activity 2 Details in the Kit Content Builder.
