Encoding Binary

Decimal to Binary • JuniorDTECH • Years 7–8 • 60 minutes

Lesson Aim

Students use their Binary Pianos to convert decimal numbers into binary and apply a simple A=1 to Z=26 classroom code to encode letters.

Learning Objectives

  • Identify binary place values and explain how a decimal number is made from them.
  • Convert small decimal numbers into binary using the Binary Piano.
  • Apply A=1 to Z=26 to encode letters, recording each letter as a separate binary value.

Teacher Preparation & Resources

  • Students’ completed Binary Pianos from Lesson 1; spare templates for absent students.
  • Whiteboard or projector, plus exercise books or the digital worksheet.
  • Prepare examples using five place values (16, 8, 4, 2, 1): 5 = 00101 and 20 = 10100.

Existing resource: Encoding Binary worksheet (Google Drive)

Lesson-specific safety: Keep desks clear if scissors or glue are needed to repair a Binary Piano.

60-Minute Lesson Sequence

  1. 0–10 min

    Starter — Revisit the Binary Piano

    Students show 3, 5 and 10 on their Binary Pianos. Revisit that a 1 includes a place value and a 0 leaves it out.

  2. 10–20 min

    Demonstration — Decimal to binary

    Model 5 = 4 + 1 → 00101 and 20 = 16 + 4 → 10100. Explain why leading zeros are shown when using five places.

  3. 20–35 min

    Guided practice — Encode numbers

    Students convert 6, 9, 12 and 17 using their Binary Pianos, then compare with a partner and correct any errors.

  4. 35–50 min

    Practical — Encode TECHNOLOGY

    Explain the classroom letter code A=1, B=2 … Z=26. Model T = 20 → 10100 and E = 5 → 00101. Students encode the remaining letters of TECHNOLOGY, keeping each letter’s binary group separate.

  5. 50–60 min

    Plenary — Check and save

    Students check two conversions with a partner and explain one place-value choice. They save or hand in the completed Encoding Binary worksheet and keep their Binary Pianos for Lesson 3.

Linked Student Activity

  • Required: Students record their decimal-to-binary conversions and the encoded TECHNOLOGY message, giving simple, checkable work for the Task List.
  • Optional extension: Encode a different short word using the same code and swap it with a partner to decode.

Important distinction: A=1 to Z=26 is a classroom code for this lesson, not ASCII. ASCII is introduced in a later lesson.
