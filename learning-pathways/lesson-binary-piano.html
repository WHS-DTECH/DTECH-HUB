Binary Piano

Introducing Binary • JuniorDTECH • Years 7–8 • 60 minutes

Lesson Aim

Introduce binary as a number system that uses 0 and 1. Students construct and use a Binary Piano to explore binary place values and represent simple decimal numbers.

Learning Objectives

  • Recognise that binary uses the digits 0 and 1.
  • Identify the pattern in binary place values: 1, 2, 4, 8, 16, 32 …
  • Construct a usable Binary Piano with movable tabs.
  • Use the Binary Piano to represent and explain a few simple numbers.

Teacher Preparation & Resources

  • Print one Binary Piano template per student, plus spare copies.
  • Prepare a completed example to demonstrate how the tabs move.
  • Have scissors, glue sticks and exercise books ready; display the place-value sequence on the board.

Existing resource: Binary Piano template (Google Drive).

Lesson-specific safety: Safe handling of scissors; keep cutting materials and glue organised.

60-Minute Lesson Sequence

  1. 0–10 min

    Starter — What is binary?

    Ask: “How many different digits does our usual number system use?” Introduce binary as a system using only 0 and 1. Explain that today students will make a model to explore how numbers can be represented.

  2. 10–20 min

    Demonstration — Place values

    Show the Binary Piano. Point out that each place value doubles: 1, 2, 4, 8, 16, 32 … Demonstrate a tab switched on (1) and off (0). Model how 5 is made with 4 + 1.

  3. 20–40 min

    Practical — Construct the Binary Piano

    Students cut and fold the tabs, checking that each remains movable. Circulate to help with construction and reinforce the place-value pattern.

    Activity card: Build Your Binary Piano
  4. 40–50 min

    Guided practice — Make numbers

    Students use the tabs to represent 1, 2, 3, 5 and 10. Ask them to explain which values are switched on and why. Students who are ready can try 16 and 20.

  5. 50–60 min

    Plenary — Explain and store

    Ask a few students to show a number and explain the tabs used. Students attach the Piano to their exercise books without gluing down the tabs. Tidy workstations.

Teacher Guidance

This lesson focuses on understanding the model, not encoding words. Save the TECHNOLOGY word challenge and A=1 to Z=26 convention for Lesson 2 — Encoding Binary.

Students should retain their Binary Pianos for subsequent lessons.
