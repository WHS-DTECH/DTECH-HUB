Your Binary Piano has five place values. Always use them in this order:

  • 16
  • 8
  • 4
  • 2
  • 1

1ON = 1 — use this place value.

0OFF = 0 — do not use this place value.

  1. Start with the largest place value that fits into the number that is left.
  2. Subtract it and turn that place value ON (1).
  3. Keep going until nothing is left.
  4. Every place value you did not use is OFF (0).
  5. Never subtract a place value that is bigger than the number that is left.

Part B

Worked Example: T = 20

  1. 20 − 16 = 416 fits, so 16 is ON
  2. 8 is bigger than 48 is OFF
  3. 4 − 4 = 04 fits, so 4 is ON
  4. Nothing left2 and 1 are OFF
