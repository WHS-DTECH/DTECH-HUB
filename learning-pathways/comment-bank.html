Reporting Comment Bank

Admin-only bank of report comments. Teachers pick one comment per category in the Progression Pathway report to build each student's Learning narrative, then edit it before it saves.

Back to Admin Menu Open Progression Pathway

How the bank works

  • Comments are organised as Discipline → Category → Subcategory → Development Level → Comment. The narrative is built in category order: Learning Context, Learning Strengths, Learning Behaviours, Next Learning.
  • Write {name} where the student's name goes and {name}'s for the possessive, for example {name} applies practical skills accurately. or {name}'s next step is to.... The first mention uses the student's first name; teachers can choose a pronoun for later sentences.
  • Use All levels for comments that suit any student (such as Learning Context). Teachers filter by subcategory and level, so keep each level's comments similar in meaning but varied in wording.
  • Inactive comments stay in the bank but are hidden from teachers. Editing or deleting a comment never changes narratives already saved for students.
  • Comments are never chosen automatically from progression results; the teacher always selects them.
